# Комп'ютерний практикум №2 — Шифр Тритеміуса

Криптосистема симетричного шифрування на основі шифру Тритеміуса (розвиток практикуму №1 «Шифр Цезаря»).

    шифрування:    y = (x + k) mod n
    розшифрування: x = (y + n − (k mod n)) mod n

`x` — символ відкритого тексту, `y` — шифртексту, `n` — потужність алфавіту, `p` — позиція літери.

| Тип ключа | Крок зміщення k | Ключ |
|---|---|---|
| Лінійний | k = A·p + B | вектор (A, B) |
| Нелінійний | k = A·p² + B·p + C | вектор (A, B, C) |
| Гасло | літера гасла, що циклічно повторюється під текстом | текстовий рядок |

## Запуск

    python main.py                       # графічний інтерфейс (потрібен tkinter)
    python demo_attack.py                # консольна демонстрація шифрування та атаки
    python -m unittest discover -v       # тести

Сторонні бібліотеки не потрібні (Python 3.9+).

## Структура

    trithemius/
      alphabet.py   Alphabet (укр. 33, укр. 35, англ. 26) та ByteAlphabet (n = 256, для файлів)
      keys.py       Key → LinearKey, QuadraticKey, PhraseKey; validate() для кожного ключа
      cipher.py     TrithemiusCipher: encrypt/decrypt для тексту і байтів, валідація даних
      attack.py     Додаткове завдання: атака з відомою парою «відкритий текст – шифртекст»
      gui.py        Інтерфейс tkinter: вибір алфавіту, типу ключа, шифрування, файли, атака
    tests/test_trithemius.py   27 модульних тестів
    main.py, demo_attack.py

## Валідація

* **Ключа** (`Key.validate`, викликається в конструкторі шифру): коефіцієнти — цілі числа; ключ не дає
  нульового зсуву за модулем n; гасло непорожнє, складається лише з літер алфавіту й не зводиться до
  самих «нульових» літер.
* **Даних** (`validate_text`, `validate_bytes`): не порожні, у тексті є хоча б одна літера алфавіту.
* **Шифрування / розшифрування** (`validate_encryption`, `validate_decryption`, `round_trip_ok`): результат
  має збігатися з еталонним перетворенням тим самим ключем; при розбіжності повертається номер першого
  різного символу. У GUI — кнопка «Перевірити коректність».

## Домовленості

* Позиція `p` рахується лише по літерах алфавіту; пробіли, цифри, розділові знаки лишаються без змін
  і позицію не збільшують. Нумерація — з 0 або з 1 (перемикач у GUI).
* Регістр зберігається. Виняток — алфавіт «Українська (35)» (33 літери + пробіл + апостроф): зашифрована
  літера може стати пробілом, тому регістр відновити неможливо, і результат завжди в нижньому регістрі.
* Коефіцієнти ключа визначені за модулем n; від'ємні й великі значення допускаються.
* Гасло: літера → її номер в алфавіті (а = 0), гасло записується під літерами тексту циклічно.
* Файли шифруються побайтово (n = 256), ключ той самий.

## Додаткове завдання: атака з відомою парою текстів

Із пари (x_t, y_t) обчислюються кроки s_t = (y_t − x_t) mod n, після чого перевіряються три моделі:

* **лінійна** — A = s₁ − s₀, B = s₀ − A·p₀; решта літер слугує перевіркою (потрібно ≥ 2 літер);
* **нелінійна** — друга різниця s₂ − 2s₁ + s₀ = 2A (mod n) дає A, далі B і C; решта літер — перевірка
  (потрібно ≥ 3 літер). Якщо n парне, рівняння 2A ≡ d може мати два розв'язки — повертаються всі
  кандидати, які шифрують однаково;
* **гасло** — шукається найменший період L послідовності s_t; перші L зсувів і є гасло. Якщо текст
  коротший за два періоди, результат позначається «ненадійно» (гасло може бути довшим).

Усі знайдені ключі додатково перевіряються шифруванням відомого тексту (`verify_key`).
Атака працює й для файлів (`attack(BYTES, plain_bytes, cipher_bytes)`).
