# Комп'ютерний практикум №5 — Шифр DES (Python + tkinter)

Застосунок реалізує криптографічну систему, еквівалентну прикладу з методички
на .NET (`DESCryptoServiceProvider` + `CryptoStream` + `FileStream`), але без
використання сторонніх бібліотек — DES, TripleDES та AES реалізовані
самостійно на чистому Python.

## Структура проєкту

| Файл                 | Призначення |
|----------------------|-------------|
| `des.py`              | Власна реалізація блокового шифру DES (64-біт блок, 64-біт ключ) та TripleDES (EDE, ключ 16 або 24 байти). Перевірено на офіційному тестовому векторі FIPS. |
| `aes.py`              | Власна реалізація AES-128/192/256 (додаткове завдання). Перевірено на тестовому векторі NIST FIPS-197. |
| `modes.py`            | Режими шифрування ECB, CBC, CFB, OFB, CTR + PKCS7-доповнення (аналог `CipherMode` у .NET). |
| `crypto_provider.py`  | Єдиний клас `CryptoProvider`, що дозволяє **динамічно обирати** один з трьох алгоритмів (DES / TripleDES / AES) та режим шифрування — виконує друге додаткове завдання. Містить методи для шифрування байтів у пам'яті та файлів (аналог `FileStream`/`CryptoStream`). |
| `main.py`             | GUI на tkinter: вибір алгоритму/режиму/ключа/IV, шифрування тексту «на льоту» та шифрування/розшифрування довільних файлів. |

## Запуск

Потрібен лише стандартний Python 3 (жодних `pip install` не потрібно —
усі алгоритми написані вручну):

```bash
python3 main.py
```

## Що показати у звіті

1. **Основне завдання** — оберіть алгоритм `DES`, по черзі перемкніть
   режими `ECB/CBC/CFB/OFB/CTR`, зашифруйте/розшифруйте текст і файл,
   зробіть скриншоти.
2. **Самоперевірка реалізації** — запустіть `python3 des.py` та
   `python3 aes.py`: обидва скрипти звіряють результат з офіційними
   тестовими векторами (FIPS 46-3 для DES, FIPS-197 додаток C.1 для AES)
   і виводять «Тест пройдено успішно» — це можна вставити в звіт як доказ
   коректності реалізації.
3. **Додаткове завдання 1** — продемонструйте роботу з `TripleDES` та `AES`.
4. **Додаткове завдання 2** — продемонструйте перемикання випадаючого
   списку «Алгоритм» між усіма трьома шифрами без зміни коду — це і є
   динамічний вибір шифру.

## Примітки щодо ключа та IV

- Довжина ключа: DES — 8 байт, TripleDES — 16 або 24 байти, AES — 16/24/32
  байти. Якщо ввести у полі «Ключ» рядок у hex-форматі відповідної довжини —
  він сприймається як hex; інакше він сприймається як звичайний текст
  (ASCII/UTF-8) і автоматично обрізається/доповнюється нулями до потрібного
  розміру — так само, як у прикладі з методички (`ASCIIEncoding.GetBytes("ABCDEFGH")`).
- Для режиму `ECB` вектор ініціалізації (IV) не потрібен — поле вимикається
  автоматично.
- Кнопка «Згенерувати» створює криптографічно випадковий ключ/IV потрібної
  довжини (`os.urandom`).
