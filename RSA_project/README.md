# Лабораторна робота №7 — Шифрування з відкритим ключем (RSA)

Реалізація асиметричної криптосистеми RSA на Python з графічним
інтерфейсом Tkinter — аналог завдання на побудову системи шифрування
за допомогою класу `RSACryptoServiceProvider` з .NET.

## Запуск

Потрібен лише стандартний Python 3.8+ з модулем `tkinter`
(у Windows він вже входить до складу інсталятора; у Linux за потреби
встановіть пакет `python3-tk`).

```bash
python run.py
```

Жодних зовнішніх бібліотек встановлювати не потрібно — використано
тільки стандартну бібліотеку Python.

## Короткий опис реалізації (для захисту лабораторної)

### Клас `RSACryptoServiceProvider` (`rsa_lib/core.py`)
Повний аналог однойменного класу з .NET:

- `generate_keypair(key_size)` — генерує два простих числа `P`, `Q`
  (тест Міллера-Рабіна), обчислює `N = P*Q`, `f(N) = (P-1)(Q-1)`,
  підбирає відкриту експоненту `e` (взаємно просту з `f(N)`) і
  обчислює закриту експоненту `d = e⁻¹ mod f(N)` (розширений алгоритм
  Евкліда).
- `to_xml_string(includePrivate)` / `from_xml_string(xml)` — аналоги
  `ToXmlString` / `FromXmlString`: `includePrivate=False` повертає
  лише `(N, e)` — те, що можна передавати відкрито; `True` — додає
  `d, P, Q`.
- `encrypt(data)` / `decrypt(data)` — шифрування `c = m^e mod N` і
  розшифрування `m = c^d mod N` з розбиттям повідомлення на блоки
  (кожен блок доповнюється байтом довжини, щоб коректно відновлювати
  межі блоків після розшифрування).

### Атака факторизації (`rsa_lib/attack.py`)
`trial_division_attack(N, time_limit)` шукає найменший дільник `N`
перебором непарних чисел від 3 до `√N` (класичний метод, що лежить в
основі найпростіших онлайн-калькуляторів факторизації). Якщо дільник
не знайдено за відведений час — атака вважається нереальною для такого
`N`.

`explore_feasibility(bit_sizes, time_limit)` автоматизує додаткове
завдання: для списку розрядностей (наприклад, 16, 20, 24, ... 48 біт)
генерує реальний ключ RSA і одразу намагається його зламати, фіксуючи
час. Результат показує експериментальну межу, після якої перебір
дільників перестає встигати за прийнятний час — це і є відповідь на
запитання "за яких значень параметрів RSA атака є реальною" (на
відміну від реальних ключів 1024–4096 біт, де перебір дільників
нездійсненний).

### Інтерфейс (пакет `gui`)
- `theme.py` — єдина точка налаштування кольорів/шрифтів ttk (тема
  `clam`, акцентний колір, стилізовані кнопки/вкладки/таблиці).
- `widgets.py` — `MonoText` (текстове поле моноширинним шрифтом з
  кнопкою копіювання) та `run_in_thread` — запуск довгих операцій
  (генерація великих ключів, дослідження атаки) у фоновому потоці,
  щоб вікно не "зависало".
- `key_dialog.py` — окремий діалог формування ключа з індикатором
  прогресу та можливістю зберегти відкритий ключ у `.xml`-файл.
- `crypto_tab.py` — двоколонковий інтерфейс "сторона A шифрує / сторона
  B розшифровує", імпорт ключа з файлу.
- `example_tab.py`, `attack_tab.py` — див. таблицю вище.

## Примітка щодо безпеки

Реалізація є навчальною: не використовує OAEP-подібне padding у
криптографічному сенсі (лише службовий байт довжини блоку) і призначена
виключно для демонстрації принципів роботи RSA в рамках лабораторної
роботи, а не для захисту реальних даних.
